# Mi Salud

App personal (PWA) para registrar entrenamiento, medidas corporales, pesadas de balanza y análisis de laboratorio.

- Funciona sin internet una vez instalada.
- **No contiene datos personales**: todo se guarda en el navegador del teléfono. El historial se carga desde un archivo de respaldo (`.json`) que no se sube a este repositorio.
