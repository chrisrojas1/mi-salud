# Mi Salud

App personal (PWA) para registrar entrenamiento, medidas corporales, pesadas de balanza y análisis de laboratorio.

**Usar:** abra https://chrisrojas1.github.io/mi-salud/ en Chrome (Android) y elija ⋮ → *Agregar a la pantalla principal*.

- Al abrirla por primera vez pide sexo, talla y fecha de nacimiento (para cintura/talla, % de grasa y rangos de laboratorio).
- Funciona sin internet una vez instalada.
- **No contiene datos personales**: todo se guarda en el navegador de cada teléfono; nadie más puede verlos. Use *Datos → Descargar respaldo* para guardar una copia.
